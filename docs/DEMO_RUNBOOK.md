# Demo Runbook (2-3 Minutes)

## Pre-Recording Checklist
- Backend running: `http://localhost:8000/api/health` returns 200
- Frontend running: `http://localhost:5173`
- Browser tabs ready:
  - Dashboard
  - Identity Graph
  - Global Map
  - Revenue Recovery
  - Compliance
- Prepare 1-2 sample assets in Assets page

## Recording Flow
1. Dashboard (20s)
- Explain platform purpose and real-time risk posture.
- Highlight that system combines forensic detection and response automation.

2. Identity Graph (25s)
- Show cross-platform offender linking and network-level intelligence.
- Mention coordinated actor detection.

3. Global Map (25s)
- Click a region and show `Why It Happens` + `Recommended Action`.
- Emphasize strategy guidance, not only detection.

4. Revenue Recovery (25s)
- Show license-vs-takedown logic and monetization path.
- Explain conversion from enforcement-only to recovery loop.

5. Compliance & Audit (25s)
- Show tamper-evident audit logs and compliance posture.
- Mention enterprise readiness and legal defensibility.

6. Google AI + Cloud (20s)
- State Gemini integration and Cloud Run deployment readiness.
- Close with real-world impact.

## Closing Lines
"AEGIS moves from piracy detection to rights intelligence, legal evidence, and revenue recovery."

"Built for real-world operations with Google AI and cloud deployment readiness."
